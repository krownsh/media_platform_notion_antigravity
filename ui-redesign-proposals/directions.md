# UI Redesign Directions — 2026-11-06

唯一功能來源：`功能盤點_20261103.md`。此資料夾是設計提案，不接線、不改現有 UI，所有數字與貼文皆為情境資料。

## 共用設計規格

- 產出：桌面 Web App Inbox 原型，1440px 寬；三版皆保留擷取、待審核、快速搜尋、導航、任務狀態與下一步的空間。
- 使用情境：一位收藏大量社群來源、需要把原始證據與知識決策清楚分開的 Owner。
- 核心準則：收進來的東西不是待辦清單；它是一個等待被理解與決定歸屬的「來源」。畫面必須讓下一個動作一眼可見，但不催促。
- 不參考現有 UI、也不讀取舊的重建文件。色彩不是從舊產品擷取：取自「墨水、紙張、螢幕訊號」三種知識工作媒介。

## 六張方向卡（先發散，再收斂為三版）

1. **編輯部指揮台**（最佳設計師思路：Eddie Opara / 政治與文化刊物的果斷編排）——黑墨、紙白與訊號橙；強規則線和超大中文標題，將審核視為編輯決策。主角是目前正在閱讀的一份來源。
2. **安靜檔案室**（最佳設計師思路：Irma Boom / 書籍的節奏和可翻閱感）——藍灰資料夾、柔白紙面、低飽和綠；以收藏的「物件感」取代 Dashboard。主角是來源卡與其媒體封面。
3. **訊號流**（最佳設計師思路：Studio Dumbar / 動態識別的節奏）——深夜藍、電光綠與半透明層；把擷取佇列畫成可辨識的資料流，主角是正在前進的工作節點。
4. **出版索引**（現實參照：Pentagram 為 Second Hand 製作的數位檔案）——檢索與 metadata 成為版面；適合極大量長期收藏，但首屏的即時擷取感較弱。參考：<https://www.pentagram.com/work/second-hand/story>
5. **當代期刊**（現實參照：Pentagram《The New Republic》數位與出版系統）——把多來源內容視為一個有鮮明觀點的出版物，適合深閱讀；但對操作型工作可能稍顯克制。參考：<https://www.pentagram.com/work/the-new-republic>
6. **高對比資料年鑑**（秒數輪盤：資料視覺化分區的 Personal Annual Report）——暖白、朱紅、石板藍與密集統計格；很適合分析頁，卻可能壓過 Inbox 的閱讀與決策。

## 入選的三版

### A — 編輯部指揮台 / `dir-1-editorial-desk.html`

- **骨架**：窄黑色導覽軌 + 寬大的閱讀／審核主欄 + 即時任務側欄。
- **借用規則**：Second Hand 的「具來源的索引」和 The New Republic 的明確標題階層，轉譯為「先讀證據、再做判斷」。
- **主角素材**：每個來源的色彩封面與一張文字閱讀卡，不做抽象裝飾。
- **大膽處**：以巨大「收件匣」作為真正的工作情境開場；橙色只表示需要 Owner 注意的決策。
- **form**：來源審核是編輯工作，不是表格填寫；編輯部的欄位節奏使「正在處理什麼」與「為什麼」清楚並置。

### B — 安靜檔案室 / `dir-2-archive-room.html`

- **骨架**：頂部像檔案索引的全域導覽 + 左方擷取與快速搜尋 + 中央大卡片堆疊 + 右方可收合的審核軌。
- **借用規則**：圖書／檔案索引的編號、紙張陰影與低彩度分類，但不模仿任何單一作品。
- **主角素材**：有實體感的來源封面與 metadata 標籤；內容先於系統狀態。
- **大膽處**：幾乎沒有「儀表板」感；把下一步做成安靜而清晰的一張工作卡。
- **form**：收藏的價值在回看；讓每個來源像可再次取出的檔案，而不是過期通知。

### C — 訊號流 / `dir-3-signal-flow.html`

- **骨架**：全高深色工作台；左列是工作區，中央是獲取／理解／決策的流，右列是詳情與候選。
- **借用規則**：Studio Dumbar 式的識別節奏，但以低干擾脈衝和可讀的節點取代炫技動態。
- **主角素材**：資料流與來源縮圖並置，清楚顯示進度、不把載入狀態藏起來。
- **大膽處**：把背景任務中心提升成主要的空間組織；特別適合高頻擷取的使用節奏。
- **form**：這個產品的關鍵不是「存下」而是「由來源走到可採納的理解」；流向本身是界面母題。
